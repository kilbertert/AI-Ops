# 共享原语速查

`common/` 是被各域复用的横切原语；每个原语刻意只有一个实现——历史教训是同一规则两份副本漂移，且漂移方向总是放宽。`async_job_lifecycle.py` 归 [gateway/gateway-store](../gateway/gateway-store.mdx)。

## HTTP 与端点

- `bounded_http.py`：urllib-only 骨架。`RequestSpec`/`ErrorMapping`/`HttpFailure`/`request_json`/`RetryPolicy`（仅 GET）/`classify_failure`；三种信封解析（raw、data_key、code_data）。`HttpFailure.cause is None` ⇔ 信封拒绝（有响应但业务拒绝），`cause` 非空 = 传输失败。`TRANSPORT_FAILURES` 是捕获集合；`AUTH_REJECTED_STATUSES={401,403}`；`_NoRedirectHandler` 拒绝一切重定向。
- `endpoint_policy.py`：`is_loopback_host` = `{localhost, localhost.}` ∪ `ipaddress.is_loopback`——**唯一的回环规则**（ipaddress 单独看不出 `localhost`）；`require_secure_endpoint` = https 或回环 http，禁 userinfo/query/fragment。
- `http_auth.py`：内部令牌 `hex(HMAC-SHA256(secret, "{ts}:{expire}"))`，走 `X-Internal-Token`+`X-Request-Timestamp`；支持多 secret 轮换；fail closed。

`request_json`/`decode_json`的可选`parse_float`默认仍为float。消费者账务显式使用安全Decimal包装器，
将构造异常映射为领域不可用，投影成金额字符串后再进入JSON响应；其他调用不变。
`code:false`被当作成功是通用信封的既有行为，本次未修，不能声称非法信封类型全部拒绝（ADR0246验收记录）。

## 文件与配置

- `private_files.py`：`validate_private_directory`/`validate_private_file`（0700/0600、属主、禁 symlink）；`write_private_text`/`append_private_text`（mkstemp+降权原子写）；`PrivatePathError`。含 Windows ACL 助手。
- `platform_paths.py`：`AIOPS_HOME`/`AIOPS_CONFIG_HOME`/`AIOPS_DATA_HOME` 覆盖；默认配置文件 = production.env。
- `config.py`：`Settings.from_env/from_config`、providers registry（`_parse_providers`，含旧单 provider 回落）、`redacted()`（配置值的脱敏投影）、`selected_config_file`。`MySQLSettings.mall_database`（`AIOPS_MYSQL_MALL_DATABASE`，默认 `qumall_mall`，空值=本环境无 mall 侧证据）：mall 是同实例独立 schema，`MySQLSource.mall_billing_records` 经它做租户+认领人绑定的跨库只读联查（联查合同归 [bounded-read-surfaces](../analytics/bounded-read-surfaces.mdx)）。

## 标量与时间

- `scalar_rules.py`：**外部标量读取与存储时间的唯一权威**（docstring 列了它取代的七个互相矛盾的时间解析器）。`as_datetime`/`as_integer` 永不抛；`parse_stored_time` 会抛；`format_stored_time` UTC+offset；`now_utc`。
- `redaction.py`：`SENSITIVE_KEY` 正则集、`redact_url_credentials`、`redact_text(preserve=)`、`sanitize_data`（上下文保留）、`contains_secret`、`truncate`（`ERROR_TEXT_LIMIT`）。
- `model_request.py`：`structured_request` 一次性结构化调用（无子进程/线程/工具循环）；原因分类：`quota_exhausted`/`auth_rejected` 不可重试，`rate_limited`/`transport_unavailable`/`invalid_response`/`upstream_error` 可重试。
- `order_reference.py`：`order_candidates`——粘贴订单优先于形状命中；数字段按区间归并；剥尾部句读；`MIN_BARE_DIGITS=15`。网关与 preview bridge 共用同一份实现。

## 语言

- `i18n.py`：`LANGUAGES` 元组是语言清单的唯一权威；`LanguageSpec(tag,name,is_chinese,fallback)`——`is_chinese` 是语言的属性而非"是否默认"（zh-Hant 会打破这个等式）；`fallback` 是每语言唯一声明的回退方向（zh-Hant 与 en 都回 zh，其余非中文语言回 en——链根是 zh 不是 en）。语言永远不扩大权限/路由/manifest。
- `answer_language.py`：输出侧泄漏闸——能证"没漏中文"，证不了翻译正确；标题豁免按来源真相不看形状：传入 `retrieved_titles` 时，资产类标题要既像资源名又在集内、其他块标题在集内即豁免；仅当未传 provenance 才退回旧形状规则（空集=不豁免任何标题）；输入合同是 `AnswerSurface` 或 `str`，其他类型 `TypeError`（形状错误不能静默换判定规则）。
