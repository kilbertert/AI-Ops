# 快速上手

用户从公司 App/H5 使用服务；开发者不再使用本地诊断 CLI。

```bash
uv sync --locked --dev
uv run aiops-admin --help
uv run aiops-gateway serve --help
uv run python .claude/skills/verify-aiops-gateway/scripts/observe.py --out dist/verification/gateway
```

最后一条在一次性配置与数据根启动真实服务并验证，不读真实业务配置。
正式配置键见根 `.env.example`；部署身份 `AIOPS_GATEWAY_ENVIRONMENT` 必填，凭据只放私有配置。
C端和管家须先有对应发布绑定，未配置时不会回落旧执行器。

开户、知识同步见[运维说明](../ops/README.md)，业务路线见[架构](system-architecture.md)，
服务升级见[环境手册](agents/env-41-runbook.md)；镜像验证见[本地构建](agents/local-gateway-build.md)。
Thin Harness、诊断/交互式/设备 CLI 和便携包已从本分支移除，详见[退役说明](runtime-retirement.md)。
