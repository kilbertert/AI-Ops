# 共享Dify转发器并发恢复回执

本事件解决[D35](../acceptance/environment-directory-qa-plan.md)真实客服候选试跑中发生的Console核权超时。
原试跑结果保留在[原回执](2026-11-20-consumer-candidate-trial-live.md)，本页只证明本次共享转发器部署与传输验收。

## 根因：流式回答与反向核权共用串行转发器

控制Gateway的Dify Service API与Console连接共用既有回环转发器。原实现同步accept→handle→pump，
流式回答连接未结束时，工具回调发出的Console读取只能排队；模型等待工具、工具等待流式连接释放，形成等待循环。

只读实测原候选应用详情GET为48毫秒；保留一条未关闭连接时第二个GET在2秒超时；关闭后恢复58毫秒。
这个最小反例不运行模型、不写业务数据。普通串行或短并发请求0.06～0.16秒成功，不能排除流式等待循环。
