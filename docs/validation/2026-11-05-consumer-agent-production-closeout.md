## 失败未隐藏

- 官方插件安装请求成功不等于升级：有旧版时install/pkg没有替换它；读取实际安装清单后按原生升级服务完成。
- 模型凭据回读掩码不能原样回写；使用官方[__HIDDEN__]哨兵保留原秘密，仅开启tool_call，未更换密钥。
- 运营预览身份误拒、订单号误脱敏均已通过PR修复和标准部署，不在服务机热改源码。
- 模型曾把差额猜测为舍入/附加费，业务提示明确禁止无证据成因后重验；不以一次符合说明保证任意语义正确。
- Agent累计text含工具过程文字，安卓出现英文过程与中文最终答复混排；提示词不足以可靠消除，#1419按真实
  agent_log提取最后无工具的成功轮次，后续最终部署证据需补齐。
- H5与手机同账号重登会使旧会话失效；重新正常登录，不注入身份。验收浏览器曾崩溃，用正常登录保存的状态恢复。
