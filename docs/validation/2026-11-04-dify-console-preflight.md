# Dify 预览控制台连接故障

日期2026-11-04；基线481f81e6，任务分支fix/dify-console-preflight。
对应[契约](../agents/operator-cpms/dify-console-preflight.feature)及[QA计划](../agents/operator-cpms/dify-console-preflight.md)。

## 原故障与根因

- 原Dify页面两次输入“天河有站点吗？”，均HTTP400、OPERATOR_PREVIEW_INVALID，未创建问答。
- 线上Gateway 1.0.22+f7002017包含#1364出站安全检查；服务控制台配置仍为远端HTTP。
  `DifyDslClient`在发请求前拒绝，外层将ValueError归类为无效草稿，桥显示通用节点授权提示。
- 同一应用、工作区、密钥、提示词和四个工具，仅在内存中切换到既有加密隧道的回环地址，
  真实DSL导出、provider核对和candidate全部通过。这是连接配置故障，不是站点数据或模型额度。
- 旧路由夹具替换DSL拉取，远端HTTP仍能创建Gateway；新增启动回归用例先红后绿，
  改后非法地址在创建数据库前拒绝，安全地址保留。
- 部署预检使用候选修订的客户端，失败时生产源码未替换、服务未重启；分类器明确报告预检拒绝。
  使用候选客户端也让回滚遵循目标修订自己的契约，不强加新版本模块依赖。
