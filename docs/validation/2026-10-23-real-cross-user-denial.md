# 真实跨用户拒绝：B 查 A 的真实订单被拒（第二窗口）

> 迁移自 `docs/validation.md` 顶部（ADR-0097 规定新记录一条一个文件；
> 本节由 #1015 在 2026-10-23 直接追加进归档文件，现移到这里，内容逐字未改）。

工具修复已被接受，这一片回到业务验收：补上一直缺的那条 ——
**真实存在的他人订单**能不能被读到。

### 参与者

| 记号 | 说明 |
|---|---|
| A | 已验收的授权账号，有本人订单 |
| B | 此前授权、**当时无本人订单**的账号；失效则记阻断，未重启登录排查 |
| O1 / O2 | A 的两张**不同**本人订单（最新 / 指定） |

开窗前用生产查询函数独立确认：**同租户**、**不同 C 端主体**、O1/O2 **属于 A**、
**对 B 不可见**。B 自己无单与本判据无关 —— 本节验的是"B 读不到 A 的单"。

### 一次窗口的四个判据

| # | 判据 | 结果 |
|---|---|---|
| 1 | A 真实 H5「本人最新一单」→ 选 O1；202 `completed` / GET 200 `no-store`；页面呈现订单、状态、来源、观察时间 | **PASS** |
| 2 | A 真实 H5 正文指定 O2 → 返回 **O2**（未回落 O1）；SQL/CPMS 独立对照一致 | **PASS** |
| 3 | B 用自己真实会话、同一确定性问句查 **O2** | **PASS**：404 `ORDER_NOT_FOUND` |
| 4 | 开关仍开时 B 回读 A 本窗口的 QA | **PASS**：404 `QA_NOT_FOUND` |
| — | 对照：A 在同一入口回读**自己的** QA | 200 `no-store`，含 `result` |

负例响应体不含订单号/状态码/`cpms.chargingInfo`/观察时间任一字段。
第 4 条是**单独**证明"结果读取隔离"，没有拿停用后的全局拒绝替代。

### 时序与隔离

窗口 **15:23:37–15:30:40 CST**。两次 POST（07:25:10Z / 07:25:25Z）各自只触发
**一次** `POST /chOrderInfo/chargingInfo/<订单号>`（200，访问日志可对时）；
两条 QA `internal_run_id` 均为 `consumer-order-chat:`；范围指纹相同（同一主体）；
私有快照 `call_id` 对上、`result_sha256` 自校验通过。

**模型调用零**：窗口日志无 model/provider/token/turn 记录；新建 run 目录 0；
`agent_runs` / `conversation_turns` 均 0；`standard_diagnoses` 未变。
**CPMS 调用次数只按可观测证据报**：本轮各 1 次；同页其他订单的 42 次不属于本轮，不下结论。

### 恢复

`gateway.env` 与窗口前逐字相同；三项在进程环境里消失、OPS 键仍在；M3 仍空；
#992 两份 nginx 制品未变；服务 active、无重启；隧道清理无残留。
停用后 A 回读两条 QA → `CHARGING_STATUS_DISABLED`（**只回读，未再提交新问题**）。

**不实施常驻开放**；是否具备讨论条件由 Codex 独立验收后决定。
