## 真实 Dify 与 Java 补验

使用 Dify 1.17.1 一次性隔离栈，实际登记 `cpms-node` provider，真实导入 agent-chat、保存 model-config、经生产 DifyDslClient 导出；Gateway HTTP 发布/试用/撤回/恢复实际驱动 Java 节点。七场景通过：双工具发布执行、单工具草稿试用且正式不变、草稿保存后App仍双工具、发布后实际单工具、全关零追加CPMS、撤回410无回落、恢复V1实际双工具。节点共13次合成模型请求；双工具含授权核对5次CPMS GET，单工具4次。公司身份/CPMS/模型及平台派发启动器仍是合成，未操作运营浏览器或真实公司业务。
