# 共享登录环境绑定开发验证

本片落实手工环境开通规划§6，验收合同为环境目录Feature/D19，设计见ADR0276。
基线 `427914de`；任务分支 `feat/console-environment-sessions`，候选版本1.15.0。
**未完成业务验收**；本记录描述隔离开发验证，合并、生产部署与目录激活均待验证。

已实现目录选环境、各环境独立正常登录与映射库、验证码环境绑定及活动会话选Gateway。
浏览器环境头不能重选管理目标；独立交换凭据防止另一环境换取公司令牌；停用/改址拒绝、退出撤销。
默认关闭多环境；默认映射库不迁移，新增环境数据根独立。登录代理/页面/桥成套部署顺序见登录代理手册。

本地365项登录、工作区、管理桥及部署检查通过；D19使用真实监听的两个HTTPS公司替身，
同号用户/租户登录后得到不同Dify账号，八次并发管理请求各到自身环境，错误交换key/退出重放/停用拒绝。
跨环境验证码、重复query、未知环境、目录改址/丢失均拒绝；未将替身登录写成公司真实验收。
首次测试发现未知环境错误分支访问不存在的异常属性造成断连接，已改为固定拒绝文案。
测试组织、路由常量、TLS替身与跨用例可变类属性亦已修正。

Chromium页面探针通过：初始验证码、切环境验证码、拒绝登录后刷新共三次请求；提交绑定第二环境，
失败后清验证码输入。页面替换已加载图片节点，避免同一nonce二次请求；浏览器第一次在开发机高负载下超时，保留失败。
本地Gateway技能实际启动服务，health200、匿名管理/问答401、OpenAPI200和旧入口404通过；不证明远端模型/知识链。
Ruff、格式、wheel/sdist构建通过；新模块分支覆盖85%，未覆盖主要为启动配置拒绝边界。
两项内存变异（去掉验证码环境比较、会话强制回默认环境）均被安全断言拦截；未改维护源码制造变异。

首次全量5247项：5200通过、9跳过、36失败、2错误。失败涉及子进程/HTTP超时、异步任务期限及安装预检内存余量；
当时开发机高负载。25项桥/脚本/入口重放通过，其余失败正在单独重放；此时不能宣称全量绿灯或归因全部成立。
