## 观察记录对应

固定 UTC 窗口后筛 `assistant_question_result` 事件，窗口内共 **3 行**，全属目标租户：

| 事件 | 观察行 | 关联方式 |
|---|---|---|
| A 查最新单 | `completed / 202 / qa_id=… / duration_ms=791` | **硬键**：`qa_id` 同时对上行与 QA 表 |
| A 指定 O2 | `completed / 202 / qa_id=… / duration_ms=693` | **硬键**：同上 |
| B 被拒 | `refused / 404 / ORDER_NOT_FOUND / qa_id=- / duration_ms=199` | **区间**：窗口内唯一 refused 候选 |

两条成功的快照 `call_id` 与 `result_sha256` 自校验通过；`internal_run_id` 均为
`consumer-order-chat:<订单号>`。三条 `duration_ms` 均非负。

**GET 不产生 POST 观察行**（隔离在服务端拒绝之前完成），这是预期行为。

## 未验证（明确保留）

1. **零模型调用 —— 未证实**。窗口内没有模型日志、没有新建 `runs/` 目录；但
   `agent_run_metrics` 与 `runs/` **都不带 `qa_id`**，无法把任何模型行归到这三条请求上。
   按口径记"未证实"，并按要求**停止新增 POST**。不得用"同租户同秒有 routing 行"推断。
2. **拒绝行没有跨层硬键**：只有"单请求区间候选唯一"。本窗口无并发，故唯一。
3. **其他租户"本来会问"**：本窗口全租户未出现 `TENANT_ENDPOINT_UNRESOLVED`，
   说明**没有观察到**影响，不等于不会发生 —— 这个开关影响整台 Gateway 的状态问法路由。
4. **端到端时延**：`duration_ms` 不含 nginx 与网络。
5. 工具自检 52 项未在本片重跑；它们不替代真实验收，也不作为本片证据。
