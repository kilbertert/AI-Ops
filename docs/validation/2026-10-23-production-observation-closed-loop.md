## 未验证（明确保留）

1. **零模型调用 —— 分两层写，不要合并成一句**：

   | 层面 | 结论 | 依据 |
   |---|---|---|
   | **同版代码路径** | 状态问法命中后直接 `return` 确定性分支，不经过模型路由/通用问答/诊断 | 逐段阅读该版本源码；独立复核用合成身份驱动真实 API 路由、在模型入口装哨兵，状态路径计数 **0**，普通问答正对照能触发哨兵 |
   | **历史供应商实际调用** | **未独立计量** | 窗口内无 model/provider/tokens 关键词、`runs/` 无新目录；但指标的 `token_count=0` 是 `record_route_metric` 的**默认值**，不是账单读数 |

   **不能说**"已证明该窗口零供应商调用"；也**不能**用"缺 `qa_id` 所以必须加全链路追踪"
   反推 —— 关联键不是零调用证明。
2. **拒绝行没有跨层硬键**：只有"单请求区间候选唯一"。本窗口无并发，故唯一，但这不是跨层硬键。
3. **其他租户"本来会问"**：本窗口全租户未出现 `TENANT_ENDPOINT_UNRESOLVED`，
   说明**没有观察到**影响，不等于不会发生 —— 这个开关影响整台 Gateway 的状态问法路由。
4. **端到端时延**：`duration_ms` 不含 nginx 与网络。
5. 工具自检 52 项未在本片重跑；它们不替代真实验收，也不作为本片证据。
