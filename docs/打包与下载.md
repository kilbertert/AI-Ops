# 打包与下载

如何构建新的 AI-Ops 便携制品，以及如何从 CI 下载已构建的 Windows 包。

> Windows 要求、首次运行、安全边界和多端 Gateway 模式见 [便携部署](portable.md)。

## 构建新包

便携制品由 `packaging/build_portable.py` 用 PyInstaller 冻结。由于 Codex SDK 携带平台专用原生 runtime，**必须在目标操作系统上构建**：Linux 机器只产出 Linux 制品，Windows 机器只产出 Windows 制品，本机无法交叉构建对方的制品。

### 本机构建

在目标操作系统上执行：

```bash
uv sync --locked --dev
uv run python packaging/build_portable.py
```

产出：

- `dist/aiops/`：PyInstaller 冻结目录（可直接运行其中的 `aiops` / `aiops.exe`）。
- `dist/aiops-diagnostics-<version>-<system>-<machine>.zip`：版本化 ZIP。
  - `<version>` 取自 `pyproject.toml`（当前 `0.1.0`）。
  - `<system>` 为 `windows` 或 `linux`。
  - `<machine>` 为 `x86_64`。
  - 例：`dist/aiops-diagnostics-0.1.0-windows-x86_64.zip`、`dist/aiops-diagnostics-0.1.0-linux-x86_64.zip`。

构建脚本会在源码目录之外解压 ZIP，以最小 `PATH` 启动它做烟测：初始化隔离私有 home、检查 key slot 和内置 Codex runtime、验证私有路径权限、拒绝制品中的秘密文件，并诊断 OCPP、YKC 金额不一致和交易数据缺失三份 fixture；Gateway 客户端还会连接本地 mock Gateway 完成 `remote enroll`、`remote doctor` 和 `remote runs`，并校验 profile/token 私有权限。烟测失败会非零退出，不会产出可分发的 ZIP。

> 本机是 Linux 时只能得到 Linux ZIP（如 `dist/aiops-diagnostics-0.1.0-linux-x86_64.zip`）。Windows ZIP 必须在 Windows 上构建，或直接从 CI artifact 下载（见下）。

### CI 自动构建

`.github/workflows/ci.yml` 在每次 `pull_request` 和 `push` 到 `main` 时运行两个 job：

| job | runner | 作用 | 是否上传制品 |
|-----|--------|------|--------------|
| `verify` | `ubuntu-latest` | 静态检查、测试、依赖检查 | 否 |
| `windows-verify` | `windows-latest` | Windows 烟测 + 构建 Windows 便携 ZIP 并上传 | 是 |

`windows-verify` 上传的 artifact 名为 `aiops-diagnostics-windows-<commit-sha>`，保留 7 天。所以每个 PR 和每次合并到 `main` 都会产生一份新的 Windows artifact。

## 下载 CI 构建的 Windows 包

Windows 包不在任何开发机上，只在 GitHub Actions artifact 里（保留 7 天）。用 `gh` CLI 下载（先 `gh auth login`）：

```bash
# 1. 列出最近成功的 CI run（取 databaseId）
gh run list --repo kilbertert/AI-Ops --limit 5

# 2. 列出某个 run 的 artifact（取 name 和 id）
gh api repos/kilbertert/AI-Ops/actions/runs/<run-id>/artifacts \
  --jq '.artifacts[] | "\(.id)  \(.name)  \(.size_in_bytes)B  expires=\(.expires_at)"'

# 3a. 用 run ID + artifact 名下载（会按 artifact 名建成子目录）
gh run download <run-id> --repo kilbertert/AI-Ops \
  -n aiops-diagnostics-windows-<commit-sha>

# 3b. 或直接拉 artifact 的 zip 字节流
gh api repos/kilbertert/AI-Ops/actions/artifacts/<artifact-id>/zip > aiops-windows.zip
```

artifact 名里的 `<commit-sha>` 对应构建时的提交，用来确认拿到的是哪个版本。也可以在 GitHub 仓库的 **Actions** 页面进入对应 run -> **Artifacts** 区，用浏览器直接下载。

### 提醒

- artifact **7 天后过期**；长期保留请下载后存入企业制品库，不要依赖 GitHub artifact。
- artifact 不是生产凭据存储，ZIP 内不含 API key 或数据库凭据。
- 当前 ZIP 未签名；企业广泛分发前应补 Windows 代码签名。
- 下载后在目标 Windows 机器上解压，按 [便携部署](portable.md) 的「首次运行」初始化。
