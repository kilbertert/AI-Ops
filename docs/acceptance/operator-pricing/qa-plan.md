# 历史计费与SOP分析验收计划

合成数据不含生产账号、订单、凭据。每项独立运行在一次性数据根。

| 编号 | 环境与前置 | 动作 | 预期 | 清理 |
|---|---|---|---|---|
| P1 | pytest；合成电量、时长及样本 | 运行test_operator_analysis | 功率算式、样本范围、缺证，不编正常结论 | 临时根自动清理 |
| P2 | 真Gateway+合成CPMS | test_operator_pricing | 快照最小投影、同轮收证与正文费用核对 | HTTP和临时根自动清理 |
| P3 | 真Java+Gateway，合成模型/CPMS | verify_operator_cpms.py | 节点调用历史工具、两侧投影一致、正式/预览可见 | 脚本关闭容器和临时服务 |
| P4 | 已合并部署，既有授权账号与订单 | 原H5与Dify依次问电费/电压/功率；独立只读CPMS核对 | 同QA证据来源、版本、规则和算式相符 | 保留业务QA，清理浏览器和临时隧道 |

未来站点方案继续独立实现与验证，本片不宣称其已交付。
真实故障根因需工程师确认；本地绿灯不等于业务准确率验收。
