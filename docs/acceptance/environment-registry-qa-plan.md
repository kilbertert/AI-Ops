# 环境登记与95重建验收计划

2026-11-14（北京时间）；用户确认由AI-Ops维护环境/租户目录，指定95清理重建用于验证。
判据来自此次确认及RFC8725的身份验证要求：目录定位不是用户身份，令牌只交给确定的环境验证。

| 编号 | 环境与前提 | 动作 | 期望及清理 |
|---|---|---|---|
| REG-01 | 两个一次性Gateway、同租户ID、独立数据根 | 经原HTTP接口分别请求 | 不共享会话/业务配置；移除临时进程与目录 |
| REG-02 | 通过公司认证的替身、已登记租户 | 停用租户后用同令牌请求 | 403且工具零调用，无须重启；恢复临时登记 |
| REG-03 | 已配置登记文件 | 损坏/移除文件、未知环境 | 拒绝，不降级到旧默认地址；清理临时文件 |
| REG-04 | 目录版本N | 两个写者均按N提交 | 一个成功另一个冲突，审计与结果一致 |
| LIVE-01 | 95受管访问、旧实例盘点 | 核进程/反代/访问流量/依赖归属，备份并校验恢复资料 | 只清理确认属于AI-Ops的资产，公司栈保留 |
| LIVE-02 | 合并制品、95独立配置/数据根 | 启动新实例、登记租户、原入口请求 | 身份/租户/数据环境一致；旧实例保持可恢复直到新验收通过 |
| LIVE-03 | 两个真实环境的账号与业务样例 | 客服、异常订单、离线查询及跨环境凭据拒绝 | 真实结果与源数据一致；缺账号/数据标未验 |

方案比较记录部署资源、开通步骤、变更/回退范围、原入口时延与故障隔离；与共享单进程方案的代码/状态迁移范围比较。
不以一次跑通宣称全局最优，不用合成数据代替真实业务验收。所有原始现场资料保存在私有证据目录。
