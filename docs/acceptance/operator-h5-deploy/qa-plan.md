# 管家 H5 部署验收

| ID | 环境/前置 | 操作 | 预期与恢复 |
|---|---|---|---|
| OH-01 | 临时 Nginx，合成身份头 | 7条声明路由与7条反例 | 个人 Bearer 原样、operator固定，伪造来源/会话头清空；反例不转发；停止临时进程 |
| OH-02 | 临时制品和配置 | 脏修订、篡改、额外文件、Nginx检查失败 | 安装前拒绝或恢复全部旧配置，旧文件保留 |
| OH-03 | 正式合并的完整公司H5构建 | 摘要核验、备份、Nginx检查、切静态根 | 制品与指定修订一致；失败按备份恢复，旧根保留 |
| OH-04 | 正常公司登录及授权订单 | 原首页进入助手，选单、发送、读取本次QA | Java与两项CPMS证据属于同次任务，页面正文可读；业务数据只读 |
| OH-05 | 同域公网入口 | 匿名QA、管理API、未声明方法 | 鉴权拒绝、管理API不代理、方法405；不扩展管理面 |

证据按制品修订、时间、用例记录。真实身份、订单和原始响应仅存私有证据；
成功接口或模型调用不能替代原页面验收，也不代表工程师已确认历史故障根因。
