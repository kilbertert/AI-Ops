# 工具拒绝回喂与原始码归因验收

环境：已授权业务环境，部署新网关与新执行节点；配置和账号来自私有清单。
网关先行还是节点先行均可灰度：两侧单向兼容，不按同一窗口上线。

|编号|前置与操作|期望|清理|
|---|---|---|---|
|F1|授权账号问一张**其他租户的真实订单号**|轮次完成而非失败；答复为「查无此单/无权查看」语义；不复述越权事实|保留QA与run记录|
|F2|同一账号问**不存在的订单号形状**|轮次完成；答复说明查无此单；日志/快照记录对应拒绝码|保留QA|
|F3|已选订单后追问一个不相关订单号|答复澄清每轮一单或确认目标，不整轮失败|保留QA|
|F4|运行中撤回发布版本或变更范围后让模型继续调用工具|运行失败；run.reason 保留节点上报的原始拒绝码（`tool_refused:`前缀）|恢复发布/范围|
|F5|旧节点+新网关（或回滚节点）问不存在订单|整轮失败、用户得到不可用结果——与改造前一致，不静默成功|恢复节点版本|
|F6|对照F1同租户可见订单正常诊断|详情/监测取证、答复与复核不受影响；拒绝清单为空时复核行为不变|保留QA对照|

不修改业务订单与权限；F4 的范围/发布变更必须恢复原状并记录操作时间。
「查无此单」类答复不得带出其他租户数据；任何答复文本中的原始拒绝码仅用于内部归因。
