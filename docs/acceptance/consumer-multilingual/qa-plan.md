# C端多语言验收计划

范围：RFC 9110 Accept-Language、BCP 47语言标识沿用既有解析；公司spanish/portuguese别名沿用既有映射。

| ID | 环境/前提 | 动作与数据 | 可观察结果 | 清理 |
|---|---|---|---|---|
| ML01 | 一次性Gateway、合成业务与模型 | 11种语言逐一发知识/状态/快捷请求 | 能力被调用、语言保持、无不支持提示 | 删除临时数据根 |
| ML02 | 本地纯函数 | 状态/账务/安全/人工/澄清按11种语言渲染 | 文案覆盖，订单与金额原样；无银行到账承诺 | 无 |
| ML03 | 隔离Dify/Gateway | 语言选择完整；蒙古/泰/高棉语运行知识与CPMS | 真Dify输入通过，保留来源及原数据 | 停栈清卷 |
| ML04 | 原H5、已授权正常登录 | 逐一选择现有9种语言，抓请求头；重点蒙古/泰/高棉语知识和本人查询，订单检测 | 设置与请求一致，答案可见且无脚本错误 | 关浏览器和隧道 |
| ML05 | 本地与隔离 | 越权订单、未知快捷、过期/撤权及历史语言 | 原有权限和失效边界保留，历史不被新语言重写 | 删除临时数据根 |

真实模型仅用于已授权渠道；不进行业务写操作。不将字符检查当作母语准确率验收。
