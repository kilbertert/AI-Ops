| 编号 | 环境及前置 | 步骤和期望 | 清理 |
|---|---|---|---|
| AG1 | 一次性Gateway+合成CPMS/节点 | 模型提议对象，工具授权后取详情/模板/账务/计算；返回计算结果后继续取证 | 关闭临时服务 |
| AG2 | 同上，已完成会话 | 传上轮实际答复；任意原句追问同单、换题找站、缺对象澄清；不依赖关键词 | 同上 |

缺原始交易/通讯API时必须保留缺证，不把有限监测或账务相符说成完整根因已确认。
