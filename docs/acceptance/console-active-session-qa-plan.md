# 活动会话验收

判据来自P1任务#1537、已确认手工环境规划及RFC8725的上下文隔离要求。
复用真实HTTP双代理及临时MappingStore；公司/Dify为隔离替身，不访问生产数据。

| ID | 前置与动作 | 期望/清理 |
|---|---|---|
| S1 | 双代理同号主体/同公司令牌正常登录；分别发布检查与交换；交叉提交、退出A再重放 | 正向允许；跨环境、未绑定及退出A拒绝且不返回身份，B保持；停止临时服务 |
| S2 | 不配置交换key，正常登录、签同账号但未绑定的会话、退出 | 正常发布规则保留；未绑定和退出拒绝；无公司令牌暴露 |
| S3 | 活动会话过期、映射用户/租户变更、disabled | 两入口均拒绝，不更新业务或权限数据 |
| S4 | 已获准测试账号、固定现役版本与配套组件，业务准入保持原状；按登录手册正常登录，读原应用/日志与发布权限检查，再从原页面退出，重放本次旧会话并重新登录 | 正向入口可用；退出后身份交换/发布权限拒绝，重登恢复；只读发布权限，不实际发布；结束仅清理本次会话，不改映射、权限或业务数据；缺前置则记阻塞 |

新增反例只保护旧检查缺失的退出与正常登录绑定；不扩大模型、订单或知识验收。
公司权限码及workspace成员仍沿用已有快照窗口；本片统一会话有效性，不声称公司侧所有撤权即时传播。

原生退出缺CSRF时403且本地绑定不变；上游失败502但本地绑定已撤销，重试不恢复会话。

S1～S3是隔离替身验证，不能关闭S4。S4记录各组件修订、配置状态、时间与用户入口结果，原始账号、
Cookie与截图保持私有。执行见[登录手册](../agents/dify-login-proxy-36-runbook.md#51-重启后的公司令牌缓存)。
本轮优先复核共享会话，不为补验重启服务或切换业务准入；重启后重登影响按既有手册告知使用者。
S4的缺口限制共享登录行为验收，不能由环境安装/目录草稿的绿灯代替，也不推导无关功能不可用。
