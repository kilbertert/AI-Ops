## 完成内容

- 先校验结构、凭据、查询参数与本轮工具证据，再用既有 Gateway 模型作一次无工具审核。
- allow 展示说明；reject、uncertain、不可用、长度或片段非法隐藏说明；Dify 预览提示隐藏状态。
- 审核不持有证据锁，完成过程串行，完成前再次授权；冻结正文与审核模型/指令摘要，回读不重审。
- 站点工具已交付时不能改 kind 绕过清单；旧快照继续兼容原渲染。验收合同与 ADR-0195 同步。
