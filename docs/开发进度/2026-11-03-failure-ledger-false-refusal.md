### 二、结算判据从「出现即拒」改为「断言形式」

第一版（2026-11-02）整段出现结算类词即拒绝，把我们**要求模型写**的内容一起拒掉：

- `请先核对账单。`、`目前没有结算状态的证据。`、`系统未提供结算状态字段。`、`您想核对账单的哪一项？`

现在：先按整句区分「纯问句 / 陈述+问句 / 纯陈述」，再要求**谓语 + 内容**才算断言。

- 名词 `结算状态` 不带谓语 → 放行；
- `结算状态是已结算` → 拒绝；
- 口语完成体 `结算了` / `结算完了` → 拒绝（第一版漏检）；
- `这单已结算是否需要帮助？` → 拒绝（第一版整句豁免把它放掉了）。

消费者端与管家端两个调用点同时生效；充电/完成状态判据原样保留。
