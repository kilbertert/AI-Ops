  `production_business_requests=0`；

  同租户条目），候选配置只做 `Settings.validate()`，**没有构造生产 app**；

## 已知缺口（不写成已验证）

1. **零模型调用未证实**：窗口内没有模型日志、没有新建 run 目录，但
   `agent_run_metrics` 与 `runs/` 都**不带 `qa_id`**，无法把任何模型行归到这三条请求上。
   按本片口径记「未证实」，并按要求停止新增 POST。**不能**用「同租户同秒有 routing 行」推断。
2. **拒绝行只有区间关联**：那条 404 没有 `qa_id`，靠"窗口内唯一候选 + 秒级区间"定位。
   本窗口没有并发候选，所以唯一；但这不是跨层硬键。
3. **其他租户"本来会问"看不到**：本窗口观察到的影响是 0，不等于不会发生。
4. **端到端时延**：`duration_ms` 不含 nginx 与网络。
5. 工具自检（52 项）未在本片重跑：本片未改工具，且它们不能替代真实验收。
