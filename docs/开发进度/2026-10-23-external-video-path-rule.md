## 2026-10-23 · 外链白名单补上 path 判据（真机抓到的）

**症状**：外部链接字段上线后在 41 上跑生产代码，`https://www.youtube.com/@trendpowercharge`
被签成了 **video 块**。那是频道主页，不是单个视频 —— 前端会把播放器挂在一个没有视频
可播的页面上，用户看到坏掉的框，而且看起来像我们的 bug。

**根因**：ADR-0111 的白名单只判 **host**。合规性上对（"这个域名我们信得过"），
功能性上不够。那份素材本来就把「视频链接」和「官方频道主页」列在同一张表里。

**修法**：host + path 两级。`youtu.be` 裸路径即视频 id 不受影响；其余必须匹配
`/watch`、`/shorts/`、`/embed/`、`/live/`。**认不出的形态一律当作不是视频** ——
漏判少一个链接，误判一个坏播放器。

**同源的一条**：频道链接排在前面时要**跳过继续找**，不能"取第一个白名单域链接"就收工；
否则真视频会被频道页挡掉。

**判据**：新增 3 条用例（频道页不签 / 四种真视频形态仍签 / 频道在前不遮蔽真视频），
去掉 path 判据的变异让其中 2 条转红。

**这一条为什么没被单测与评审抓到**：单测里我喂的是"视频标题 + 视频链接"的干净样本，
而真素材里混着频道页。**判据的样本要取自真实数据，不是从方案里推想出来的样本。**

见 ADR-0113。**交付**：本分支。
