## 目标与交付

测试同事获得一份可单独转发的[接口文档](../testing-api-guide.md)，并可从现有API域名
读取OpenAPI JSON、导入测试工具。文档覆盖C端与管家个人鉴权、23个用户操作、curl、
请求响应、异步轮询、取消、会话、知识/媒体、多语言、权限负例和15类功能用例。

新入口 `/v1/openapi.json`、`/v1/docs` 仅公开已选用户方法/路径。请求约束来自FastAPI
模型，公网身份按代理语义描述；内部管理/回调不随默认文档一并公开。
规范与无外部脚本的中文查阅页随Gateway交付；无需新增Nginx配置或端口。
