# 281. 现场预检回执先由固定安装器只读取证

状态：已采纳；接续ADR0280，不开放中央部署或自动激活。

## 决定

原安装器增加preflight及编号回读，同环境安装锁下只核自有已安装实例、制品/配置/目录摘要、
待恢复状态、服务版本/监听归属、schema和在飞任务。固定路径和服务身份沿原安装合同，未知实例不收养。
预检只写root控制的自有回执目录，不修改installed/pending或业务库，不启动/停止服务。
同安装和观察状态15分钟内复用编号；实际摘要、就绪、PID/启动时间或恢复状态变化使原回执expired。
资源余量使用P3启动下限，记录观察值；资源门槛类别参与指纹，短时数字变化不制造重复回执。

本机检查与受管SSH身份、正式双向网络、真实业务分开，后三项pending；所有回执executable=false。
回执不含秘密或私有路径，阅读旧编号仍实时核对，不能把文件存在当持续健康。
后继任务执行端可整合现场证据，本片不在生产Gateway部署SSH密钥或接受浏览器的passed字段。

## 替代方案

直接把SSH与主机私钥放进Gateway可让按钮立即探测，但扩大业务服务权限与访问面，且重复dev-host身份断言。
接收浏览器上传任意JSON最快，却无法证明目标确实执行或状态仍有效。
为每次就绪读创建通用任务引擎可以统一异步过程，但本片只是已有安装器的一次只读操作。
选择固定安装器持久回执，后台安装/资源任务在后继沿冻结输入接入。

## 后果

原install/recover命令与回执不变，preflight拒绝部署载荷；CLI编号读取无任意路径。
回执文件0600、目录0700、服务身份不能写；格式/跨环境/不一致记录拒绝，数量超过界限要求人工归档，不自动删除历史。
使用systemd的[MainPID和启动时间](https://www.freedesktop.org/software/systemd/man/latest/systemctl.html#show%20%5BPATTERN%E2%80%A6%7CJOB%E2%80%A6%5D)
作为服务实例观察，源制品沿P3摘要合同，时间沿原15分钟计划窗口。
通过只代表指定时点的已安装实例就绪和启动余量，不是业务容量、模型/知识活性或租户开通。
