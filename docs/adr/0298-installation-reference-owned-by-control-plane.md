# 298. 安装执行引用不从租户模板投影

状态：已采纳；防止客户环境模板改变中央安装控制面。

## 决定

`AIOPS_GATEWAY_ENVIRONMENT_INSTALLATION_FILE`是41控制网关专用安装调度引用：把已登记部署目标指向其专属节点私有文件，仅由控制面受控流程维护。
它绝不进入目标124的租户production.env。环境投影拒绝该键，就像拒绝环境registry/onboarding路径一样。

控制端运行时由受控production配置读取引用；目标只收到固定安装器批准的制品/停用候选资料，不会收到账本路径或控制端节点引用。
节点文件沿已有权限私有配置复用；不得因缺失而新建猜测内容。管理员能访问目标主机也不意味着业务模板可配置控制平面路径。

## 替代方案

把installation引用复制进业务模板后投影到每个租户，表面容易部署，但租户输入可重定向安装任务到任意节点引用；不采用。
把控制安装引用混入统一业务references，把控制面/业务面权限合并；改用独立固定受管文件。
新建一套节点/主机映射的编辑页面或配置存储会重复环境目录与主机角色真值；本片只读复用目标引用和节点私有文件。

## 后果

客户端可改草稿不能改变目标安装/执行节点；引用缺少/不安全时fail closed。控制安装引用只在41按现有目录权限和合并制品部署维护。
引用更新与124安装为两个不同写操作，分别记录CAS/备份/回退；租户草稿与正式准入保持独立。
