# 298. 安装执行引用仅由控制面维护

Status: Accepted

租户配置模板属于业务环境输入，不能决定中央控制面把安装任务派往哪个节点。

## 决定

`AIOPS_GATEWAY_ENVIRONMENT_INSTALLATION_FILE` 是控制 Gateway 的专用安装调度引用，用于将已登记部署目标绑定到其专属节点私有文件。该引用只能由控制面受管配置维护，不能投影到租户的 `production.env`。投影器遇到模板显式声明此字段时拒绝整个投影；正常模板不含该字段时，现有投影不变。

目标节点文件继续沿现有受控私有配置路径读取；目标服务只接收固定安装器认可的制品和停用候选配置，不接收控制面的节点引用。引用更新与目标安装是两个分开的写操作，继续使用现有摘要比较交换（CAS）、备份、安装器和回退流程。

## Alternatives considered

- **允许业务模板携带安装引用。** 它让每个目标配置可独立设置，但租户模板便能重定向中央安装任务；不采用。
- **把节点引用并入通用业务目录。** 这可减少配置入口，但会混合控制面派发权限与租户业务配置；不采用。
- **新建节点/主机映射管理面。** 这可显式展示映射，但本次只需维护已有部署目标引用，会重复现有环境目录和主机角色来源；不采用。

## Consequences

租户草稿和模板不能改变控制面的安装节点，缺少或不安全的控制引用仍按现有合同失败关闭；安装引用只由控制面按受管流程更新。代价是首次配置仍需运维设置该控制引用，且引用更新和目标安装必须分别审计、分别回退。
