# 265. 公司网关来源证明先于用户授权，重放账本独立保留

Status: Accepted（落实用户2026-11-14确认的接入架构）

新业务环境显式启用RS256短时来源断言，固定签发环境、公钥与原HTTP请求摘要，随后仍执行现有用户认证/资源授权。
本片来源证明不签发业务权限，也不能替代公司侧token级登录环境绑定。先实现验证接缝，签发与只读接口未配套时禁止开启生产。

防重放使用本环境独立gateway-admission.db，复用gateway_db连接/事务，不把高频临时nonce加入业务库schema迁移。
它只含issuer/jti/到期时间，最多保留凭据有效期内记录；进程重启仍拒绝重放。同身份多进程必须共享文件；
多宿主不能各存副本，需单入口或后续统一nonce存储。不恢复过期备份覆盖现用nonce库，丢失账本后至少等待全部120秒凭据过期再接流量。
与仅进程内缓存相比，独立SQLite可跨进程/重启拒绝重放；与共用业务库相比，避免认证洪峰争用业务写事务。
