# 169. 知识连接ID属于工作区

日期：2026-10-29
状态：已采纳

## 决策

真实优链充RAGFlow已能建库、解析、检索，但Dify同步失败：全局API模板UUID来自Ulink工作区，
新工作区没有自己的连接。Dify 1.17.1原生ExternalKnowledgeApis的tenant_id及查询范围都是工作区。
因此开户与同步共同确保当前工作区连接：旧UUID仅在其所属工作区复用，新工作区按平台受控
endpoint/key创建并核tenant_id；在同步并发闸内查询/创建，响应丢失后按本工作区稳定名称回读。
没有扩大知识key权限、没有复制客户文档，凭据仍由现役Dify补丁加密保存。

## 被否掉的替代方案

- 直接复制外部API UUID：UUID是工作区资源，不是跨租户连接。
- 仅手动给优链充创建连接：下个客户仍失败；创建必须进入同一个开通与同步流程。

## 验证

两工作区连接分离、重试复用、错工作区返回拒绝、同步使用目标连接均有测试；
真实RAGFlow测试文档已经DONE并检索命中，Dify端仍待合并部署后复测。
