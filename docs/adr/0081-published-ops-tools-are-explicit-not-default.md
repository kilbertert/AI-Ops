# 新工具只能显式发布，空集合必须撤权

新名字加入合法目录，但历史 `ALL_TOOL_NAMES` 默认保持七项。已发布 `allowed_tools` 是放行权威，
草稿未发布不授权。绑定新执行面的 Dify 拉取将全关闭/删除解释成新权限为空，绝不恢复默认新权限。
同 app 未声明旧 provider 时保留旧发布权限；明确声明旧 provider 则按其勾选更新旧权限。
这是迁移兼容规则，不是第二份工具授权表。不同工具不可凭名字相似互相映射。

每次读前、返回前核对当前绑定和发布版本；读取期间变更即拒绝正文。
外部 HTTP/业务库和 Gateway 状态不是分布式事务；返回前核验是放行时点，不保证随后撤权追回已披露正文。
本片允许 draft 行继续使用其已发布版本，disabled 拒绝；不改其它执行面的生命周期（#922）。
