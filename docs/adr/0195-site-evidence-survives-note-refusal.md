# 195. 可信站点清单独立交付，说明单独审核并冻结

日期：2026-11-03
状态：已采纳（交付取舍由用户确认，真实业务验收待执行）

## 决策

替代 ADR-0194 中「说明拒绝则整轮失败」的决定。查询权限、凭据、结构、参数与工具证据
仍由程序检查，失败整轮拒绝。只有经过这些检查的清单才可独立交付。说明由无工具的独立
模型请求审核事实与能力边界；拒绝、不确定、超时或无效响应时隐藏说明，运营预览说明此状态。
复用 Gateway 已配置模型与有界 HTTP 请求，不新增服务、依赖或凭据；不审核订单与账单。

审核在任务证据锁外执行，每个完成过程串行，完成前再次检查运行与当前权限。保存最终采用
的说明、渲染结果、审核版本及模型身份；回读不再随机审核，仍执行撤权检查。旧快照沿用
原渲染检查。模型不能授予权限，也不能覆盖确定性事实。

## 标准与边界

RFC 8259 仅约束 JSON 语法；严格解析不证明事实正确。OWASP LLM Prompt Injection Prevention
Cheat Sheet 的 Model-Based Guardrails 强调审核模型也可被注入：固定指令、数据分离、无工具、
最小事实输入与确定性授权同时保留。同模型独立调用仍存在同源失效，不能保证任意文本零幻觉。
审核增加一次有界调用与成本；服务不可用时仍有清单。

## 被否掉的替代形态

- 字符启发式便宜且确定，但无法区分类别词与名字，也缺少查询事实；不再扩大词表。
- 全部开场改为固定模板最简单，但失去业务提示词风格；仅在说明不可交付时保留系统清单。
- 不合格就重写并重审能提高说明展示率，但增加延迟和随机步骤；本次不自动重试。
- 在渲染或回读时审查可以少存字段，但历史结果会随机变化；只在完成阶段审查。
