# 168. 站点搜索丢弃模型说明，结果只来自CPMS

日期：2026-10-29
状态：已采纳

## 决定

真实流式模型为正确站名条件附带“为您查询充电站”说明，原校验因text非空拒绝了整次搜索。
site_search的text从不参与查询或结果生成，因此在字段类型/长度及搜索词校验后将其清空，
不展示、不持久化。站点名称地址继续来自CPMS，租户/站点/分页/取消检查不变。
answer与order_required仍要求有效正文并执行原只读声明检查；凭据检查保持在清空之前。

## 被否掉的替代形态

- 加重提示词后等待模型偶然服从：不是执行保证，且该字段对搜索没有用途。
- 将模型text拼入搜索结果：可能混入编造站名或已退款等虚假声明，破坏事实边界。
- 忽略所有未知字段或放宽条件：超出此次根因；字段形状与条件白名单继续严格校验。

回归覆盖正常进度说明和含假站名/退款声明的说明；两者均先红，再证明实际CPMS结果正常交付且
模型说明没有留在run快照或结果中。
