# 304. 新租户运行快照累积现役目标而不覆盖环境

Status: Accepted（2026-11-22，主会话确认P4先行运行连续性依赖）。

## 决定

原候选安装入口在目标按已记录前驱组合consumer targets，原八文件形状保持，注册描述仍表示本次租户；
全量工作区/应用登记继续以原数据库为准。组合工件显式标输入与前驱摘要，不伪称与上传包相同。
共享节点、模型、工具manifest和凭据不同拒绝混合，留给独立配置窗口。旧单租户工件继续可读。

已有租户启用状态来自当前受管目录；新候选不能关闭/移除已有租户，新租户仍关闭。
已有在用配置只保留原运行开关，其他字节变化须独立配置事务。原安装器pending/installed与恢复仍唯一，
目录恢复产生新revision，不覆盖业务数据库。候选验证核本次租户停用而不要求其他租户一起停用。

## 备选方案

每租户一套环境配置可自然隔离文件，但重复运行节点与秘密并产生多份映射；直接替换原单租户包会丢掉旧目标；
新目录旁挂第二运行台账增加漂移，均不采用。仅放宽validate_candidate不能证明原准入未扩大，不能单独交付。

## 后果

首次已有环境升级仍可能重启本项目Gateway，需明确零在飞维护窗口，不声称旧租户零中断。
此片只让已有租户保持、新租户可准备与验证，不签正式grant、发布或激活；P4正式发布恢复继续后接。
