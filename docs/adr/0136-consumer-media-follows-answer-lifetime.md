# 136. 客服素材随其回答失效

Status: Accepted

## 决定

已审核内容快照保存FAQ→媒体ID与固定知识库/文档/图片身份。只有本轮检索命中的已审核FAQ
可以签发其素材；模型仍只选择FAQ，不生成媒体URL。沿用image/video blocks、MediaResourceSigner
及现有RAGFlow媒体读取，支持浏览器Range，不新增外部抓取地址或任意媒体代理。
素材仅来自登记的知识库；图片MIME/视频MIME各按既有白名单，不把宣传外链当操作教程。

WF01素材的有效期同时受签名TTL、同QA成功状态、当前绑定与审核内容摘要控制；读取媒体前后
都核对该QA仍可交付。撤回/换绑/过期不继续交付素材。签名链接仍是可转发的短期凭据，
不声称能追回已下载内容；客服素材不得包含订单、用户身份或个人数据。

## 替代方案

不直接使用检索内容里的URL，也不把旧手册图全部视为已审核素材；未配素材时保留文字。
不依赖旧Agent知识库绑定判WF01素材生效，WF01沿用自己的运行/发布边界。
RFC9110 Range沿用既有实现；链接授权沿用现有协议，并非新增客户端身份协议。
