# 135. 订单账务记录不是银行收付款证明

Status: Accepted

## 决定

复用CPMS订单详情的订单金额、支付金额字段和退款状态/金额。源码把payAmount在费用计算时设为
订单金额，因此不能据此输出支付成功；refundStatus是业务记录，不能据此承诺银行到账或时限。
接口未给币种，答案明确缺失并请对照原订单。金额仅展示、不计算，不以浮点运算结算。
JSON金额先按平台解析再经Decimal校验有限非负值；保留返回精度，不补币种或四舍五入。
该映射遵循RFC8259的JSON数值/空值区分，未知退款码保留待核实，不强转为成功或零。

绑定显式启用live_billing_record，执行记录data_kind固定billing；客户端或模型不能改工具用途。
仍须本人选单、orders:read、单轮grant、读前读后和回读授权，使用现有实时轮次记忆隔离。
只调用详情GET，不调用退款申请或支付状态变更接口。操作说明问法仍走知识，不因“退款”误触查询。

## 替代方案

不把payAmount当支付成功、不把充电结束当退款完成，也不复用商城售后接口替充电订单作结论。
独立供应商交易状态尚未接入，明确保留该缺口；有了授权的真实支付渠道凭证后才扩展到账结论。
