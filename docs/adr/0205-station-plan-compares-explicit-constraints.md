# 205. 站点方案比较明确约束下的连续充电费用

状态：已采纳。日期：2026-11-04。

未来方案从指定可见站点的规则取证，不使用历史订单金额推断费率。复用QA、节点授权与
对象证据契约，新增管家专属operator_conversation工具用途；消费者和订单诊断不可调用。
按既有无订单能力声明装配，不修改任何已发布订单工具集合。cpms_station_plan是组合只读
工具：站名搜索唯一结果→核站点归属→沿模板引用→按指定日期选季节/节假日→计算并冻结。
模型只提议原话参数，系统计算正文和规则随同次证据交给节点确认，不能让模型重写价格。

用户须明确站点、绝对日期、同日时间窗、电量、持续功率、计费时区，以及普通按量、无优惠、
不预约、不选保险、充完离场条件。只继承同主体同应用会话上一条成功计划的用户条件，
新站点/日期重置，不继承历史答案或规则。取数及结果回看重验当前站点归属。

首片比较未来31天内同日、一次连续充电的分钟开始时刻；分段积分，电/服务分别两位
ROUND_HALF_UP，固定启动费后计税，税额同样两位HALF_UP。与最早开始的含税价比较节省。
金额套餐是预付限额，须覆盖估算与最低启动门槛；不能当成折扣。季节和节假日模板依
上游真实实现；有待生效规则、停车收费、非零电损、复杂套餐、按时长收费、夏令时切换日
或跨日时不宣称最优，明确要求补核适用条件。真实硬件功率不由计划保证。

采用ISO 8601日期/时间书写与IANA时区标识；时段23:59仅在上游模板终点表示日终，
用户23:59仍为该分钟。原接口使用GET且已读控制器确认无写入；对象授权延续OWASP API1。
税额按已核对结算实现的费用合计乘税率；有优惠时不套用这个无优惠模型。

## 被否掉的替代形态

不跨站点全局寻优，不替用户下单或启停充电；不按历史订单反推官方价格。
不将新能力归入消费者共享conversation用途，以免用户未要求的消费者权限扩大。
不将缺字段置零后宣称最低价；不另建会话数据库和持久任务调度器，复用已有生命周期。
