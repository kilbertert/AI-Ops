# 278. 计划与安装器共用只读归档校验

状态：已采纳；承接ADR0277，不开放远程执行或激活。

## 决定

P3应用包校验归入gateway.environment_artifacts，管理计划直接调用；独立安装器携同修订的固定副本，
冷安装先加载随包模块。旧安装器的恢复仍使用原制品，不要求目标先安装新Gateway。
计划新增应用/安装器成员完整性与包内修订分项；不能用声明的外层SHA代替包内清单。
安装器归档只允许固定普通文件及完整SHA256SUMS，读取REVISION，永不导入其中代码。

## 替代方案

直接在Gateway复制P3检查可以少改部署资产，但两份成员/Python规则会漂移。
把安装脚本动态导入到管理进程能复用现有函数，却让待验证制品参与执行，也要求服务部署整份运维脚本。
独立安装器只导入目标已安装包实现最省打包，但首次安装无包，升级又会误用旧版本规则。
选择一个标准库模块、安装器携固定副本，保持独立冷安装和管理服务读取边界。

## 后果

应用归档沿原P3清单/Python合同，安装器格式兼容此前五文件制品和新增校验模块的六文件制品。
安装器构建同步复制源模块，原安装/恢复及无预装包的加载验证均须保持；管理桥和CLI仍调用同一计划实现。
校验只证明成员摘要、内部声明与目标Python相符；不证明wheel代码、Git合并来源、签名供应链、
配置投影、主机身份、现场网络或业务。所有计划仍blocked/executable=false；其余条件由后继执行前复核。
