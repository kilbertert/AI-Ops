# 293. 受控开通配置模板按摘要更新

状态：已采纳；接续ADR0292。读者为环境开通和部署维护工程师。

## 决定

已登记环境的配置模板继续作为受控 references 的一部分维护。aiops-admin environment-artifacts
可在同一次授权、目录锁和旧摘要 CAS 中接收一个新的 configuration 引用：先按目标草稿渲染并校验，
再把文件复制到 onboarding-assets/configurations/<sha256>.env 的0600固定副本，最后原子替换
references 并保留旧完整备份。应用包、安装器、配置编号、主机和租户准入仍分别校验；缺少或越权的
模板、摘要漂移、备份冲突和模板覆盖安装器生成字段均拒绝。该命令不访问目标、不安装、不重启、不激活。

安装仍由现有冻结计划和安装器的 --expected-config-sha256 完成；配置引用变化会使旧计划失效，
因此必须重新预检并使用同版安装器升级。这个边界允许为停用候选配置独立的管理密钥，同时保持正式租户关闭。

## Alternatives considered

直接在目标 production.env 追加密钥最短，但绕过了制品、CAS和回退账本，也无法证明操作者更新的是
登记环境；不采用。为一个候选试运行新增独立配置分发服务会重复现有目录与安装器边界；不采用。

## Consequences

配置变更有固定摘要、备份和现有安装器回退路径，应用/安装器引用和配置引用仍由同一目标记录绑定。
每次模板更新都要求重新预检和一次受控升级；命令不会自动验证目标网络、模型、工具或业务能力。
