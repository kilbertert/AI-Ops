# 247. 客服订单事实由程序呈现

Status: Accepted。2026-11-12用户明确选择“继续调整事实呈现方式”。

本次真实记录回放中，即使移除冲突运营指令、商城状态码并反复约束原值，模型仍无依据声称
“充电正常结束”。因此覆盖ADR0232中订单回复完全采用模型正文的决定：Dify继续决定取证，
但涉及本轮订单工具或会话内订单时，最终金额、税项、状态、缺证与异常边界由程序从本轮成功
工具记录直接呈现，丢弃模型自由订单正文；不靠数字集合或状态关键词检查猜语义。

知识问答保留模型检索与内容选择、原来源/媒体规则。独立验收证实“纯知识”的关键词判定
无法排除“这笔充电”等指代与其他语言，因此最终统一展示来源原文摘录，
不允许通过知识分支重开无证据订单断言。订单与知识混合提问附本轮资料原文摘录与来源，
不把模型对本单的推断夹在事实后面；没有订单证据时固定说明未取得，不从历史答案或用户描述
补事实。不增加模型调用，不改变业务权限、取数预算、既有历史/撤权校验或callback1–5。

取舍：订单回答更固定，资料摘录可能不及模型摘要简练，翻译/改写暂不自由交付；该限制换取金额和状态不被模型改写。
这只保证交付不引入模型派生事实，不证明上游记录正确、资料适用或故障准确率。
新的事实文案先提供中英，其他语种按既有i18n清单回退；状态名称复用现役语言映射。
