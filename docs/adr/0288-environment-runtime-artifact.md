# 288. 候选应用与专属节点以私有运行工件接线

状态：已采纳；接续ADR0287。读者为开通/部署工程师，解释运行接线与激活的边界。

## 决定

复用已准备的双端应用和知识资源；运行目标由受管运维明确选择的环境专属节点配置决定。
同编号租户不能从中央默认profile借节点或服务器。节点模型出口沿专属配置，管家模型名/参数与
已批准的候选编辑模板一致；SOP/工具从当前仓内声明生成，不继承早期单工具测试清单。
在现有aiops-admin增加导出操作，读取冻结plan和原候选任务，实际Console只读验证后产生私有工件。
工件复用AgentRunConfig、NodeTarget及消费者目标格式，附接线/输入摘要；秘密不进入公开回执。
本片不安装配置、写正式路由、生成应用key或授予业务准入。后继安装/试运行须用此明确工件，不能手工挑字段。

## 替代方案

直接注册到中央最少步骤，但中央执行环境和数据源仍是41，会误绑同号主体；不采用。
复制41整份profile容易满足原发布器，却带入源节点目标/凭据和过期模型选项；只复用批准模型子模板。
直接边配边启用较快，但配置与候选事实未冻结且掉线无法核对；选择先导出可检查工件，再按受管安装事务接入。
另建运行配置中心能统一编辑，但已有私有引用、任务账本和配置格式足够；本片不增加常驻服务/通用调度器。

## 后果

旧草稿投影和候选应用合同保持；未配置专属节点时新操作拒绝，不阻断原准备流程。
导出只证明资源/接线一致，不能证明节点在线能力、正常目标登录、模型/工具run、知识质量或业务准确性。
安装仍需配置与恢复点成套，正式目录指针须在业务验收之后激活；这两步不由导出动作代办。
