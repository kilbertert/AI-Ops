# 138. 客服发布冻结内容与能力

Status: Accepted

## 决定

复用Agent不可变版本与chat_route_bindings，服务端目标声明标明WF01应用、内容文件、知识库和只读能力。
发布时从已审核内容读取快照，与Dify已发布workflow身份共同冻结；运行使用该版本中的内容，
不再从草稿文件读取。只改内容或能力也产生新版本。恢复旧版本恢复对应内容，撤回保留路由并拒绝正文。
路由场景从可信目标/已管理行识别，不从客户端请求或模型决定；目标与节点目标冲突拒绝。

## 替代方案

不把可变content_file路径当发布内容，不在Dify保存时自动切版，也不为WF01另建版本权威。
只复用旧个人状态的固定场景会撤错路线，故按同应用的管理行定位。原workflow/node路线保留。
跨系统发布仍无事务：先验Dify冻结图一致，再推进带revision的路由；不承诺已发数据可追回。
