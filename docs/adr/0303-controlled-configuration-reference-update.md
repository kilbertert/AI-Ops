# 303. 配置版本复用受控引用CAS而不修改派生安装包

Status: Accepted（2026-11-22，用户批准D40配置修复与额外一次自有Gateway重启）。

## 决定

原environment-artifacts增加互斥configuration输入，保留已有配置ID，比较引用与原配置双摘要，
原投影检查模板，私有保留新版本后原子切换引用并备份旧文件。原应用/安装器用法不变。
引用是唯一配置源；不得在派生包临时加密钥后继续用旧引用生成下一包。
缺本机验证密钥在副作用前明确拒绝，worker只透传该白名单码，其他未知结果不变为可重试。

## 备选方案

手改目标env或派生包可快速恢复，但破坏安装账本或下一次投影丢配置；新配置管理表会制造第二真值，均不采用。
复用原引用事务保留原身份、共享目标授权、私有文件和回退纪律，不新增模板保留键例外。

## 后果

配置修改须重新预检和原成套安装，旧计划失效；先更新引用不代表生产生效。
不复制控制端或模型密钥，目标独立HMAC由批准的配置变更准备。业务、准入与真实根因验收不因拒绝路径通过而完成。
