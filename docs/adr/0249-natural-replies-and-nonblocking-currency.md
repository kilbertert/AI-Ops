# 249. 恢复客服自然答复，币种标注不单独阻断管家分析

Status: Accepted（2026-11-12用户明确要求客户端恢复昨天自然语言和提示词，管家忽略单独币种问题）。

用户认为固定证据代替分析影响使用，且尚无业务反馈要求币种一票否决。决定恢复客户端
11月11日最后正式版本的自然语言正文和提示词（主租户V27、第二租户V5）；恢复原有
Agent正文+来源/媒体的交付函数，删除退出主路径的程序事实呈现器及其专属检查。
此项更新ADR0247的取舍，回到ADR0232的表达方式；不回滚新增商城证据、金额原字段、
取数/回读权限、取消、过期和既有链接脱敏。即时危险的既有固定提示、
按语言提供的官方客服入口及非found来源过滤保留，不随自然正文恢复退回旧缺陷。提示词仍要求金额只读原值、不作二次推算，
但不再声称程序可证明任意自然语言金额或状态正确。

管家复核继续摘录currencies供内部观察，但不由该数组强制reject；语义复核也明确不能
仅因币种名称/符号/单位拒绝。金额数值变造、换汇推算、站名编造及其他无证据断言仍按
既有事实判据处理；不是把有币种的所有reject改为allow。此项更新ADR0219的币种部分，
其他事实及名称归属不变。历史unsupported_currency记录不改写，新生成侧规则同步。

## 备选方案

- 只修改客户端提示词：当前程序丢弃模型正文，无法恢复昨天回复方式，用户已明确否决。
- 所有复核reject都放行：会连实际金额错误和虚构操作一起放行，超出本次要求。
- 只删除程序币种检查：语义复核仍可能按旧指令拒绝，需要同步判据；历史日志不追溯改写。
- 新建开关或双套渲染器：本轮是明确恢复，不新增无人要求的长期模式和配置分叉。

接口blocks、字段值、身份及知识引用沿用现有合同，未新增协议。客服自然正文只说明已取资料，
知识质量和业务结论仍须真实验收。恢复提示词通过正常草稿hash校验和发布，不直接写数据库。
