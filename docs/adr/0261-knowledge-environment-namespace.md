# 261. 共享知识服务的身份包含业务环境

Status: Accepted

95接入发现kb-service只按tenant-id保存RAGFlow账号；两个独立Gateway不足以隔离共享服务中的同编号租户。
启用平台环境登记的实例，开户、检索、媒体和凭据操作统一使用环境/公司租户的无歧义编码作为知识服务身份；业务API和本地账本仍保留原公司租户ID。
发布前的知识库归属与文档检查也使用同一身份，重新绑定租户时保留环境。启用登记而环境为空时拒绝装配。
编码采用RFC 8259的JSON二元素数组及RFC 4648第5节的URL安全Base64（省略填充）；只是身份编码，不提供加密或鉴权。
替代方案是每环境复制知识服务，增加维护成本；仅换开户邮箱不换请求头会继续共用旧token，均不采用。未启用登记的旧41继续原标识，既有知识数据不迁移；后续纳管现役环境需显式迁移，不能直接开开关。
