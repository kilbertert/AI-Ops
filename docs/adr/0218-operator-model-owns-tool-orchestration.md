# 218. 管家模型决定取证与表达，工具层独立授权

日期：2026-11-05。

Status: Accepted（用户已批准架构草案并授权实施）。

自然语言理解不能由关键词表代替。管家统一为一个模型工具循环，模型提议订单/站点与
后续工具，Gateway校验对象来源、当前权限、参数、发布清单和证据归属。
只读工具不接受租户、凭据、SQL或任意URL；单次诊断只绑定一个通过授权的订单。

会话上下文由Gateway从所属会话加载并重新核对历史对象权限，包括实际交付回答；
节点不接受平台任意附带的历史。SOP来自版本化发布内容，计算来自受控工具结果。
关键数值/状态/核验项由工具提供，模型据此自然表达；交付前复核事实和限定。
自由文字沿用已有单次语义一致性复核，范围改为完整答复与本次证据；它不选路由或工具，
不授予权限，不再按数字词表拒绝。拒绝/不确定不交付，且不触发无限修复循环。
业务反例与实测评价仍必需，不声称模型复核能证明任意自然语言推理。

删除关键词承接、关键词选字段、无订单时自动替换工具集和固定整页事实段的现役路径。
历史已冻结结果仅用于授权回读，不以旧版本渲染规则控制新模型。未发布新契约不得静默
扩大旧应用工具授权；配套节点/声明先就绪，再发布目标应用，保留已合并旧制品回退路径。

沿用Spring AI Tool Calling的模型选择→应用执行→结果回模型循环与Chat Memory职责；
受控消息与工具定义是本地协议，Python/Java必须同样验证。工具载荷JSON按RFC8259，HTTP GET依RFC9110，确定性金额沿用ADR0211，权限不因模型提议而产生。

本ADR取代ADR0201将“模型选字段”等同“模型认定真实性”的取舍，并更新ADR0202仅给
历史问题的限制。不会删掉C端原有语义分类或把两个产品的授权范围混为一谈。
验收见operator-agent-loop feature/qa-plan；具体API覆盖缺口仍按业务证据记录。

真实模型回放显示七字段/两字段最终JSON都会夹带散文，业务最终答复不需要这层协议。
新operator-agent/1直接交付最终自然语言，结构化只用于工具调用/结果；
删去最终JSON解析/装饰修复路径，不因自然答复格式进行整轮重派。

## 备选方案

- 继续扩充关键词和固定报告：每种自然问法都要增加路径，且会覆盖运营发布的SOP，否决。
- 模型直接访问CPMS并自行算金额：对象权限、计费舍入和证据归属无法独立保证，否决。
- 保留最终JSON并反复修复格式：真实模型回放仍夹带散文，增加延迟且不解决事实正确性，否决。
- 采用当前模型循环：增加明确的跨层版本迁移成本，换取统一的自然语言承接；
  权限和计算仍由系统执行，语义复核与真实业务验收分别记录证据边界。


真实Java＋现取CPMS实验继续暴露字段路径占位符索引虚构，整轮被引用解析拒绝。
因此最终答复同时移除占位符协议与解析器：模型直接复述工具给出的计算，系统附取证来源，
沿用完整答复的事实一致性复核。确定性保证覆盖计算和权限，不覆盖模型复述的任意语义；
不为错误索引增添猜测修复或宽松解析。失败反例保留，原入口验收仍必需。


复核范围扩大后，生产Responses模型默认推理耗尽1024乃至4096令牌，只返回reasoning项。
本次仅复核调用显式使用reasoning.effort=none，保留1024输出上限和20秒超时；其他调用默认不变。
映射依据[Responses推理说明](https://developers.openai.com/api/docs/guides/reasoning)：输出预算
含推理令牌，未完成响应不得当作结果；兼容供应商实际行为以本轮探测为准，不推断所有模型支持。
实测none返回完整reject（7输出令牌），没有把缺失结果默认为通过；完整正反整链仍单独验收。
