# 试运行的可见范围跟随发起人（管家端口径），缺身份则退回调试租户

日期：2026-10-15
状态：已采纳
影响版本：PRD #772 F（子票 #782）；`dify_trial.build_trial_scope`、`POST /v1/dify/trial` 的发起人头

## 背景

#781 的试运行把订单范围钉在**配置的固定调试租户**上（顶层账号口径）。那是刻意的第一版：
在没有"按人范围"的时候用最小暴露面把功能跑通。但它的后果是**任何人**都可以对那个租户的
任何订单试运行 —— 试运行因此成了一条按请求查单的通道，只是恰好被限制在一个租户里。

#782 要求把范围换成**发起人本人按管家端（``operator``）口径**的可见范围。

## 决定

**范围由发起人的公司身份决定，规则与会话路径同一份。**

* 桥从登录代理取发起人的公司身份（B 端 ``sys_user.id``、``tenant_id``、``sys_user.type``），
  经请求头转达给 AI-Ops；AI-Ops 用现有 ``scope_context`` 按 ``operator`` 口径算可见站点。
* 顶层账号（``sys_user.type ∈ {-1, 1}``）⇒ 整个租户；其余（代理商）⇒ 店铺 → 站点集合。
* **浏览器提交的租户/站点/用户字段继续一律忽略**（请求体 ``extra="forbid"``，多一个就 400）。
* 桥没给全身份 ⇒ **退回 #781 的固定调试租户行为**，且仍只对 owner/admin 开放。

## 三条要写下来的判断

### 1. 「用现有的 ``scope_context``」是准确的 —— 依赖早就在网关里

核实后修正了初稿的担心：网关**已经**有 `UpmsOperatorSiteScope(settings, credential)`
（`gateway_api._operator_site_scope`），由 `Settings.upms.base_url` + 内部凭据构造 ——
那正是第三方会话与 C→B 映射路径**已经要求**的同一套配置。站点归属映射走既有隧道
（`mysql_site_mapper`），**不为授权另开连接路径**。所以本票没有引入新的凭据来源，
也没有扩大直连边界。

### 2. 范围构造器必须**注入**，不能由运行时 import

第一版在 `gateway_runtime` 里 `from aiops_diagnostics.gateway_api import _operator_site_scope`，
立刻形成 `gateway_api → gateway_runtime → gateway_api` 的环，被
`test_package_import_graph_stays_acyclic` 判为 README 分层说明失效。改成装配层
（`create_gateway_app`）构造后 `set_trial_operator_scope(...)` 注入。这不只是绕开检查：
构造它需要的 `Settings` 与凭据**本来就是装配层持有**的东西。

### 3. 与「问的 == 跑的」同一条

路由拿**同一个** `ScopeContext` 问 `order_authorizer`（越权与不存在同为 404），worker 拿
**同一个**对象去执行（`resolve_query_scope` 下推）。两个范围来自一次构造，所以不可能漂 ——
这正是 #781 那次真缺陷（用 `admin_context` 的 `self` 范围，连一张订单都解析不出）的反面。

## 被否掉的替代形态

* **桥直接传站点集合。** 那让范围成了**请求**的一部分，而它必须是身份的产物；一个能自报
  站点集合的请求就等于"以任意站点试运行"。
* **在网关里新建一条打 UPMS 的连接。** 不需要 —— 那条链已经在，且已经由别的路径日常使用。
* **缺身份时也 fail-closed（拒绝而不是退回调试租户）。** 那会让 #781 已验收的固定租户行为
  在**没有映射**的环境里整体不可用，而 PRD 明确要求"没有映射时退回 #781 的行为"。

## 后果

* 试运行的可见范围 = 该发起人在管家的可见范围：代理商只看名下站点，顶层账号看整租户。
  「本人作为消费者下的单」按管家端口径**看不到** —— operator 是站点范围，不是 ``self``。
* 解析失败（UPMS 不可达、凭据未配、店铺无站点）一律 **空站点集合**，即看不到任何订单：
  与会话路径的 fail-closed 同向，不回落租户级、也不套用 ``self``。
* 权限码快照仍是**最近一次登录**的（#779 定了它的窗口上界）；本票不放宽也不收紧它。
