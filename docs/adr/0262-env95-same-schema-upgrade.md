# 262. 95首次重建与后续制品升级分开

Status: Accepted

首次重建已保存旧系统恢复点，不能删除installed标记后再次调用首次安装器。后续升级复用制品预检，
保留配置、数据和首次重建标记；只接受相同数据库schema与服务单元，在飞请求为零才停机切换。
停机后二次检查防止检查窗口内的新请求被遗漏。失败恢复原制品，不自动覆盖数据库。
在飞检查复用GatewayStore的JOB_TABLES，包含草稿预览与健康报告，不能只看已签发节点任务。
这仅是95当前同schema发布合同，新增迁移需另行设计；健康通过不代表业务验收通过。

替代方案：删除首次安装标记后重建会破坏恢复关系，直接覆盖运行代码则没有完整制品校验与回退，均不采用。

应用预检以服务身份aiops执行：配置/数据库属于该身份，root仅负责系统安装与切换，不能放宽私有文件属主校验。
