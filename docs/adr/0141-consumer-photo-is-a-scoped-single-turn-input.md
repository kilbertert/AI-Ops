# 141. 用户图片是一次性范围输入

Status: Accepted

## 决定

图片以原始JPEG/PNG上传到有身份的Gateway端点，4MiB/1200万像素上限；Pillow解码、纠正方向、
缩小并重新编码，丢弃元数据。只在内存存放规范化图，5分钟失效，每30秒清理；每主体最多2图、
进程最多32图，使用后立即移除，重启即失效。ID绑定主体与发布摘要，不能任意URL抓取或跨用户使用。

Dify沿用1.17.1官方/files/upload的multipart file+user及chat-messages的local_file上传ID协议。
图片轮次和下一轮不继承上游对话。识图结果只是非可信检索提示，不决定订单身份、权限或实时事实；
最终只输出已审核知识，模糊图追问。原图不写本地磁盘；Dify仍按其自身策略保存上传文件与运行输入，
不声称Gateway删除可追回上游副本，正式启用必须落实对应保留策略。

## 替代方案

不接受外链图片，不把base64原图放进问答或日志，不只查扩展名。图像解析依赖Pillow而非自写解码器。
不通过用户照片自动定位订单，不在图像分析后直接执行停充、退款或派单。
