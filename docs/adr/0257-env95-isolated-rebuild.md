# 257. 95从旧实例重建为独立测试环境

Status: Accepted

用户授权清理95陈旧AI-Ops以验证平台环境登记，旧0.1.0及空Gateway库不做原地迁移。
采用合并修订的离线wheel/依赖包、新安装目录与空数据根，继续使用该项目已有nologin服务身份。
备份旧文件和SQLite一致快照，候选通过后切原8788，真实验收后才退休旧路径；失败恢复旧服务。

替代方案：原地覆盖会丢掉可比较的旧状态，重装整机或删除公司数据库超出任务且会破坏其他服务，均不采用。
Dify/模型仍共享，95仅部署必要项目进程；既有公网域名与公司业务路由保持，性能与维护成本按实测评价。

独立反例要求安装时严格匹配清单文件集合、拒绝目标路径软链接，并以尝试ID区分失败现场；退休只有完整移动后写完成标记，中断后可续跑。

文件集合只排除根SHA256SUMS，不能按basename排除子目录同名文件；后者会形成未验证内容入口。

切换临时链接同样带尝试ID；失败后不能让下一次ln跟随残留目录链接，成功current必须与本次备份属于同一尝试。

真实构建的uv输出附带.gitignore；构建端移除该非依赖文件，安装端继续要求wheelhouse仅含wheel，不因工具附带文件放宽契约。
