# 166. 试运行不解析正式绑定的空清单

日期：2026-10-29
状态：已采纳

## 决定

受管应用试用绑定只有profile/模板路径，`manifest_text`为空；真正草稿清单已经冻结在run。
无订单回合只在非trial分支转换并比较正式清单。试用仍核对本次run的摘要、当前主体、
应用绑定revision、节点和任务状态。结果回读使用相同分支，不触碰无关的正式空字段。

## 被否掉的替代形态

- 将空字段填成临时草稿：试用会影响绑定含义，而且没有正式版本的草稿同样不能成立。
- 允许JSON解析空字符串：掩盖真正损坏的正式清单，不改变错误的提前求值位置。

现场ulink普通无订单试用在节点领取前失败；新增空绑定整链回归先红，修复后通过。
