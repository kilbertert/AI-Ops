# 清单加载保留Dify工具权威

日期：2026-10-25
状态：已采纳

## 决定与背景

已有规则规定Dify绑定的agent不在清单填写allowed_tools，收敛时保留发布版本的工具集合。
WF01收尾dry-run却报告updated：加载器将所有缺省工具字段都归一为全工具，提前抹掉了绑定条目的哨兵。
只对未绑定条目做默认归一；绑定条目保留哨兵，沿用既有_converge_one保留逻辑。
这是修复既有权限来源约定，不新增协议或权限。

## 备选方案与后果

- 在WF01清单硬写空工具：违反单一权威，且加载器本就拒绝，弃用。
- 不同步清单：未来收敛可能恢复旧应用，弃用。
- 不修加载器只改收敛：被抹掉的来源无法可靠还原，弃用。

回归必须从真实TOML load_manifest进入reconcile；以前手工构造哨兵的测试绕过了缺陷。
空集合与单工具集合均保持版本不变，未绑定默认行为仍由原测试覆盖。
