# 203. 历史计费读取快照，计算与证据一起冻结

日期：2026-11-04。

状态：已采纳。

计费属于只读诊断，不执行后台重算。新增订单工具读取当时的模板快照与分时费用；
延续ADR-0146的节点调用、Gateway逐次授权和双方收证。快照没有站点字段，Gateway在
读取前用同一公司身份重查订单站点，再核对快照的订单与租户；不由模型选择对象。
嵌套数据由唯一工具声明给出白名单，两侧限制深度、数组数量和文本长度，原始个人字段不进入模型。
新对象响应使用request-target/2，既有工具仍用/1，以便先部署兼容节点再升级Gateway。
能力心跳声明支持/2；发布含快照的应用必须匹配/2，旧工具可由两版节点服务。

系统用Decimal及ROUND_HALF_UP生成明确算式并在完成时冻结；模型只写语气和追问。
历史快照缺失不能回落当前模板。分时展示电量可能由金额除以费率产生，所以它与费率相乘
不能作为独立计量证明；费用合计一致性与原始计量、协议分支及最终应付正确性分别陈述。
两份根目录SOP是业务参考，其中人工处置不构成自动执行授权。

适用依据延续RFC 9110只读GET语义与OWASP API1对象授权；已核对上游控制器无写操作。
金额舍入沿用公司实际费用实现，不宣称任意币种都使用两位小数。

## 被否掉的替代形态

替代方案“完成回调中隐藏取费”会绕过已发布工具面；“让模型自由算金额”不可稳定复核，因此不采用。
