# 266. 共享Dify备用HTTPS只承载受限服务API

Status: Superseded in part by [0306](0306-formal-scoped-dify-service-ingress.md)（第二环境入口的临时生命周期被替代；原受限传输边界保留）

目标环境到共享Dify原HTTPS多次在握手阶段被重置。临时边缘代理试验出现403/525，已完整回退。
选择在共享服务宿主的已分配端口池中增加备用TLS入口，保留原域名证书和应用Bearer，只允许已批准来源。
客户服务器不安装SSH业务隧道，公司代码、业务网关和数据库不改动。

入口仅转发固定Dify服务API，不开放控制台、内部开户或任意URL；原正式入口保留。
来源清单私有维护；API日志不包含query、Authorization或正文。Nginx已有TLS支持，无需新增常驻代理进程。
若云边界不通则撤回，不擅自修改公司安全组。临时入口48小时后必须复查原路径和保留决定。

这解决的是传输可达性，不能替代公司身份、租户/订单授权、真实业务验收或一键开通。
替代方案：边缘代理增加外部链路且本轮不稳定；关闭TLS验证/明文连接破坏凭据传输合同；专属SSH通道已被用户否定。
