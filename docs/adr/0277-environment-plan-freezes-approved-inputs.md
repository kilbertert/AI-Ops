# 277. 开通计划冻结目录版本和受控部署引用

状态：已采纳；实施已批准P4的冻结计划步骤，现场执行与激活尚未开放。

## 决定

复用目录草稿的SQLite与锁保存开通计划，以环境、草稿/目录版本、制品摘要和配置版本构成内容摘要。
相同输入跨浏览器/设备返回同一编号；读取时重核当前授权及输入摘要，漂移即过期。
私有部署引用清单只定位受管目标、固定制品及配置，不存另一份公司/Gateway地址。
浏览器只提交环境和草稿/目录版本；不提交路径、命令、通过状态或验收结论。

先交付可独立使用的配置/制品预检与计划回读；缺引用、文件不私有、摘要错配按明确阻塞返回。
现场主机身份、容量、正式双向网络和三功能候选证据不由本机文件检查证明，计划始终不可激活。
下一片执行器必须重新核冻结输入并读取现场证据；不能复用应用开户账本来默认重试主机安装。

## 替代方案

浏览器随机request_key易复用既有开户接口，但换设备就重复任务，且开户未知结果与主机恢复边界不同。
直接将表单地址转成SSH/HTTP命令能快速演示，却将管理页输入变成任意访问。仅存摘要不存版本不能说明输入为何过期。
另建通用任务引擎可处理更多任务，但重复现有目录锁和SQLite；本片用现有职责内计划表。

## 后果

依[RFC9110 §9.2.2/§13.1.1](https://www.rfc-editor.org/rfc/rfc9110.html#section-9.2.2)将重复请求映射为内容唯一计划，
将版本前置映射为JSON目录/草稿CAS；SQLite原事务防并发重复。
配置秘密不入计划或回执；私有路径只留受控清单，回执只给编号、摘要、结论。正式开通仍有明确未验条件。
