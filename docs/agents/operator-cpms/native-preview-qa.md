# 原生预览与正式开放验收

| ID | 环境与输入 | 执行 | 期望与清理 |
|---|---|---|---|
| NP-01 | 本地隔离 Gateway、合成公司身份/CPMS、当前草稿 | 预览传入不同于保存版的提示词和工具 | 执行清单使用本次草稿；正式指针不变；fixture 自动清理 |
| NP-02 | 真桥 HTTP、合成 Dify/登录/Gateway | 无会话、CSRF错误、错应用、无订单、越权/未知工具 | 前置拒绝或授权拒绝，不放宽身份、不发无授权业务请求 |
| NP-03 | 真浏览器、原生请求形状与合成节点结果 | 发送/显示结果/停止，普通非管家预览对照 | 原面板消费 SSE；停止取消；其他应用请求不被截获 |
| NP-04 | 生产公司登录与授权明确订单 | 原生预览正例/不可见单，核同 run 节点及证据 | 正例终态/双工具，拒绝无正文；会话失效明确报告，不能伪造映射 |
| NP-05 | 正式 Java 节点、原问答 POST/GET | 原发布启用、明确订单、缺订单/无身份 | active 持续开放；回读同 QA；不撤回已获持续开放授权的路由 |

生产操作先备份 DSL、路由、部署制品与摘要；失败按受影响对象恢复，不恢复整库。
预览是单轮单订单，模型配置仍来自节点平台；不支持无订单选单和继承前次订单。
所有真实登录、订单、SSE、令牌证据存私有目录。工程链路通过不代表故障结论业务验收。
