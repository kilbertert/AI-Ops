# 管家 CPMS 工具验收计划

首片输入是已授权的一张订单；正式 B 端入口、发布控制与业务准确率分开记录。

| ID | 环境/前置 | 操作 | 可观察判据 | 清理 |
| --- | --- | --- | --- | --- |
| API-01 | 源码固定修订、线上制品只读 | 比对接口、DTO、查询与制品类 | 接口形状及版本缺口有据可查 | 原件仅私有保留 |
| TOOL-01 | 真 Java 工具、回环 CPMS 合成 HTTP | 调详情与监测两个工具 | 固定请求、同订单字段、范围核对、无个人敏感字段 | 关闭回环服务器 |
| TOOL-02 | 同上 | 参数注入、错订单/租户/站点、缺字段 | 拒绝；参数注入零上游请求 | 同上 |
| TOOL-03 | 同上 | 重定向、超量响应、业务错误、撤权/到期 | 无正文、无回落、凭据不进错误 | 同上 |
| PUB-01 | 隔离 Gateway、真节点及编辑器 | 草稿关闭、发布关闭、全关、撤回、恢复 | 实际工具调用与 CPMS 请求随正式版本改变 | 清理本任务隔离根 |
| LIVE-01 | 正常管家登录、真实授权站点及异常单 | 原页面单次提问并回读 | 真实报告、工程师对照；站点外拒绝 | 恢复本次临时绑定 |

当前实施阶段优先完成 API-01 和 TOOL-01..03；PUB-01、LIVE-01 尚未执行时明确记待验证，不能以工具类测试代替。真实请求预算与对象在执行前具体记录。模型沿用 baoyun，首期无业务写动作。
