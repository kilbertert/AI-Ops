# 客服选库与发布恢复验收

判据来自用户本轮确认、知识选库合同与 ADR-0255。所有合成验证使用临时数据根。

|用例|环境/前置|操作|可观察结果/清理|
|---|---|---|---|
|PS1|临时Gateway，有已发布旧应用与新草稿|删除新草稿所选库，首次发布；改选授权新库并改提示词，再发布|首次拒绝且不污染草稿/正式版；重试发布同一份新内容；fixture清理|
|PS2|旧版留下系统创建、未编辑、未发布的受管草稿|修改Dify选库及提示词后发布|复用原Agent恢复；人工更新/他人创建/不同应用记录拒绝接管|
|PS3|真实Dify组件，删除库A、新库B|仅勾对客授权，再在本应用选库移除A并选B，预览/发布|授权不改选择；失效引用可见；选库走原生保存，保留其他字段；浏览器清理|
|PS4|保存错误/只读/并发修改|改选后保存失败或另一标签页改变hash|不假报保存或发布成功，不覆盖并发草稿|
|PS5|原Dify、获准租户、新库已有资料|私有备份草稿/路由，原页面选库与预览，正常发布，原H5提问|QA精确版本/提示词摘要/知识引用一致，旧版本仍可恢复；关闭隧道，不删业务数据|

新增回归只覆盖已复现的半发布与误选路径；权限检查沿用既有跨租户/撤权用例。
生产发布需当前任务交付授权，单测与合成浏览器成功不计为PS5通过。
