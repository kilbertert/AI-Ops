| ID | 环境/前置 | 操作与期望 | 清理 |
|---|---|---|---|
| OPS-01 | 临时 Gateway、真实本地 agent/workspace/registry，合成业务 | HTTP 请求两工具；列表有界、状态订单一致、证据摘要对应正文 | 结束本次进程，删除临时根 |

| OPS-06 | Dify console 合成 HTTP | 首次创建，重复配置零写；不同 schema 或 key 冲突明确失败 | 关闭合成服务 |
