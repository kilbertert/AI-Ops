# 客户端本人订单状态查询验收

本片由用户明确授权：不修改公司仓库，同时支持指定单与本人最新一单。
沿用 App 的 `/v1/assistant/questions` 与 `type=qa/result.blocks`，后端确定性只读，不新增模型循环。

| ID | 环境/数据 | 操作和期望 | 清理 |
|---|---|---|---|
| COC-01 | 临时库、consumer、自身/他人/工单订单 | 最新选单按租户及本人 SQL 过滤，稳定排序；只读一单状态 | 删除临时根 |
| COC-02 | 同上、回环 CPMS | 指定本人订单；回答、快照、摘要及来源一致，模型/诊断调用零 | 停回环服务 |
| COC-03 | 缺凭据、all/organ/代查/缺 C 身份、无本人订单 | 401/403/404，CPMS 调用零 | 同上 |
| COC-04 | 授权故障、CPMS 错单/坏信封、读取后订单转他人 | 503/502/404，不返回状态正文 | 恢复替身 |
| COC-05 | 证据文件写失败 | 503，不能宣称成功，生成槽释放 | 同上 |
| COC-06 | 未启用、诊断/扣费/快捷动作、普通知识问答 | 原路由保持；不会因运维配置而启用 consumer | 同上 |
| COC-07 | 两用户/两订单、未知状态、会话 | 不串单，no-store，未知不推断；结果和会话可回读 | 删除临时根 |
| COC-13 | 真 Gateway + 真节点端点、合成 CPMS | App 聊天 → 节点：POST 立即 202，GET 轮询到 completed，blocks 等于该 run 快照；每个成功请求派发一次、业务读取一次 | 停进程与端口 |
| COC-14 | 同上 | 最新单与正文指定单选到不同订单；QA↔run 是存储关联（`agent_runs.qa_id`） | 同上 |
| COC-15 | 同上 | 节点失败 / 执行配置漂移 / 未预期异常 ⇒ QA 落 failed，**不回落直读**（CPMS 调用 0） | 同上 |
| COC-16 | 同上 | 非本人订单在派发**之前** 404；未配置绑定或绑定外请求走原直读分支 | 同上 |
| COC-17 | 同上 | 取消先落终态并撤销关联 run；迟到成功不覆盖取消；停用后回读 404 `CHARGING_STATUS_DISABLED` | 同上 |
| COC-18 | 真 uvicorn + TCP | POST 不等待节点（<2s 返回），随后原 GET 轮询到答案 | 停进程与端口 |
| COC-08 | 真 Gateway HTTP，一次性根，构造会话及回环业务源 | 驱动既有 App HTTP 接口及同源响应形状，记录 build/时间/请求计数 | 停进程与端口 |
| COC-09 | 同上 + 回环 introspection | 成功、缺读权限、订单不可见、租户未登记、CPMS 失败、显式订单在路由前被拒、未预期异常、同秒并发：**每次候选请求恰好一行**，成功带真实 `qa_id`，拒绝不带，`stage` 指得出拒在哪一步 | 停进程与端口 |
| COC-10 | 同上 | 普通问答、功能关闭、身份未建立：**一行都不写**（日志为空即通过，不是"没看"） | 同上 |
| COC-11 | 同上 + 人为延迟 | `duration_ms` 覆盖 SQL 与 CPMS：给两段各加 120 ms，读数必须 ≥ 240；把计时挪到 QA 落库之后该判据必须转红 | 同上 |
| COC-12 | 单元 | 日志行不含问题、回答、订单号、会话、令牌、原始异常；`error_code` 只收稳定码；写日志抛错不改变响应 | 无 |

观察契约见 [observability.md](observability.md)。COC-09～COC-12 证明的是**观察**，
不是业务验收：真实用户、真实 MySQL、真实 CPMS 仍记为**未完成业务验收**。
