# 客户端本人订单状态查询验收

本片由用户明确授权：不修改公司仓库，同时支持指定单与本人最新一单。
沿用 App 的 `/v1/assistant/questions` 与 `type=qa/result.blocks`，后端确定性只读，不新增模型循环。

| ID | 环境/数据 | 操作和期望 | 清理 |
|---|---|---|---|
| COC-01 | 临时库、consumer、自身/他人/工单订单 | 最新选单按租户及本人 SQL 过滤，稳定排序；只读一单状态 | 删除临时根 |
| COC-02 | 同上、回环 CPMS | 指定本人订单；回答、快照、摘要及来源一致，模型/诊断调用零 | 停回环服务 |
| COC-03 | 缺凭据、all/organ/代查/缺 C 身份、无本人订单 | 401/403/404，CPMS 调用零 | 同上 |
| COC-04 | 授权故障、CPMS 错单/坏信封、读取后订单转他人 | 503/502/404，不返回状态正文 | 恢复替身 |
| COC-05 | 证据文件写失败 | 503，不能宣称成功，生成槽释放 | 同上 |
| COC-06 | 未启用、诊断/扣费/快捷动作、普通知识问答 | 原路由保持；不会因运维配置而启用 consumer | 同上 |
| COC-07 | 两用户/两订单、未知状态、会话 | 不串单，no-store，未知不推断；结果和会话可回读 | 删除临时根 |
| COC-08 | 真 Gateway HTTP，一次性根，构造会话及回环业务源 | 驱动既有 App HTTP 接口及同源响应形状，记录 build/时间/请求计数 | 停进程与端口 |

真实 App/正常登录本人样本/工程师业务结论未到位时写“未完成业务验收”。本地替身不计真实业务通过。
新的生产配置仍默认关闭，合并部署后只读复核；不借 operator 整租户 key 启用此功能。
