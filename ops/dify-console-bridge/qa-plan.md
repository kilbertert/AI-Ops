# 发布桥修复系统验收计划

## 当前状态

本地专项测试通过不代表生产通过。部署前必须从合并修订构建制品，确认桥的固定工作区与网关导出工作区相同，并补齐控制台 origin；缺配置时不得启动新桥。不得在服务主机手改运行代码。

## 用例

| ID | 环境与前置 | 操作 | 预期可见结果 | 清理 |
|---|---|---|---|---|
| PUB-01 | 隔离 HTTP 测试；有效 Cookie/CSRF、固定工作区 owner/admin、已绑定 app | 点击发布 | 明确成功动作及有效版本号；浏览器不含机器密钥 | 关闭测试服务 |
| PUB-02 | 隔离 HTTP 测试；普通成员或其他工作区管理员 | 请求发布 | 403；网关未收到发布调用 | 关闭测试服务 |
| PUB-03 | 隔离 HTTP 测试；错误 Origin、CSRF 或重复安全头 | 请求发布 | 4xx；未访问上游 | 关闭测试服务 |
| PUB-04 | 隔离 HTTP 测试；上游重定向、refused/failed 或畸形结果 | 请求发布 | 非成功；重定向目标未收到凭据 | 关闭测试服务 |
| PUB-05 | 本地 compose 自检 | 执行部署 check，含非回环绑定反例 | 正向通过，0.0.0.0/省略地址/IPv6 通配均拒 | 删除检查临时目录 |
| PUB-06 | 服务环境；合并制品、配置齐全、备份可恢复 | 核对制品摘要、工作区一致、内部监听及注入脚本 | 与合并版本一致；内部入口仅回环，脚本可访问 | 保留旧产物作回滚，不退役旧入口 |
| PUB-07 | 真实浏览器；受控 app 与允许发布角色 | 改提示词，保存但不发布；随后点击 AI-Ops 发布 | 保存不改变线上版本；点击才产生可确认发布结果 | 还原提示词并显式发布，记录恢复版本 |
| PUB-08 | 真实业务链路；已授权 operator 与受控订单 | 请求诊断并核对选版 | 实际消费已发布版本；返回契约与授权范围保持 | 不记录令牌/订单号，保留脱敏证据 |

## 记录要求

每项记录时间、构建修订/摘要、环境、步骤、状态码和脱敏结果。PUB-06 至 PUB-08 未执行时标记未完成，不把 API 写配置称为浏览器编辑，也不把 HTTP 回放称为 APK 真机验收。模型准确性需工程师确认，不能由标记匹配推出。
