# 公司正式网关来源凭据签发工件

这是本仓原创的JDK17+纯标准库签发器，不是公司源码快照，也不是已上线的Spring过滤器。
合同见[来源校验](../../../docs/agents/company-gateway-admission.md)，AI入口同时继续校验原用户和资源范围。
公司网关必须先验证本环境真实会话（后台须token级登录绑定或环境独立签发者，消费者须本环境thirdSession），
清除外来断言，并在路径/查询/正文/身份头最终改写后调用sign；收到凭据的代理不能再改签名字段。
私钥由公司配置系统持有，公钥对应AI侧固定issuer/environment/kid。禁止把签发器公开成匿名签名接口。

当前未修改/部署公司仓库。公司侧需交付：登录签发时登记token摘要及有效期、退出/撤权失效、固定AI路由过滤器、
窄权限只读回调与受限路由发布。单纯安装本Java类不满足上述前提，不能开启生产来源门。
验证使用隔离RSA密钥做Java签发→Python验证；具体构建/证据见本轮validation，不能由互通推出公司网关已上线。
